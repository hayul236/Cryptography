# **Cryptography Labs**

This repository contains **7 lab exercises** for Cryptography.

## Lab Descriptions

- **block_cipher** – Implementations and experiments with block cipher algorithms.  
- **dhke** – Diffie-Hellman Key Exchange simulation.  
- **md5** – MD5 hashing and its applications.  
- **mod_arithmetic** – Modular arithmetic operations for cryptography.  
- **rsa** – RSA encryption and decryption exercises.  
- **shift_cipher** – Classical shift (Caesar) cipher implementation.  
- **substitution_cipher** – Classical substitution cipher exercises.
